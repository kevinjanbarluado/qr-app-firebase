# Frontend - QR App

React frontend application with Vite and TypeScript for the QR app.

## Features

- User registration form
- Admin login page
- QR code scanner for admin
- Modern, responsive UI
- TypeScript support

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```

## Pages

- `/` - User registration page
- `/login` - Admin login page
- `/admin` - Admin dashboard with QR scanner

## Components

- `Registration` - User registration form
- `AdminLogin` - Admin authentication
- `AdminDashboard` - QR scanner and user verification

## Dependencies

- react - UI library
- react-router-dom - Routing
- qr-scanner - QR code scanning
- vite - Build tool
- typescript - Type safety
